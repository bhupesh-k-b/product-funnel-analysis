# Tableau workbook and dashboard recipe

The repository includes `tableau/product_funnel.twbx`, generated by `python -m src.build_tableau`. A `.twbx` is a ZIP containing `product_funnel.twb` and three aggregate CSV sources in `Data/`. Those aggregate sources come from the SQL pipeline and are small enough to inspect directly.

The workbook uses Tableau's legacy XML format for broad compatibility. Package and reference validation passes; runtime rendering has not been tested in Tableau Desktop/Public. If prompted for a missing source, choose **Edit Connection** and select the matching CSV from `tableau/Data/`. The unpackaged `.twb` expects that relative `Data/` directory.

## Build the views manually

Tableau supports delimited text sources through **Connect → Text File**: [official connection instructions](https://help.tableau.com/current/pro/desktop/en-gb/examples_text.htm).

1. **Conversion funnel:** connect `data/processed/funnel.csv`; put `stage` on Rows and `SUM(users)` on Columns and Label. Sort ascending by `stage_order`. Use bars. Add `overall_rate`, `step_rate`, and `dropped_users` to Tooltip. Format rates as percentages. The generator prefixes stage names with their order in its packaged copy.
2. **Retention heatmap:** connect `retention.csv` as a separate source. Put `cohort_week` on Rows and discrete `week_number` on Columns. Put `AVG(retention_rate)` on Color and Tooltip; use Square marks and a sequential blue palette. Filter `fully_observed=1` and `complete_acquisition_week=1` for fully observed cells and complete acquisition cohorts. Null outcome cells mean unobserved, not zero retention. Do not SUM rates.
3. **Early signals:** connect `segments.csv`; put `feature` and `segment` on Rows and `AVG(later_purchase_rate)` on Columns. Add `users` and `later_buyers` to Tooltip. Display all three feature groups separately; each is a different segmentation of the same population. Their denominators overlap and should not be summed across features.
4. Arrange these sheets on a 1400 × 900 dashboard. Add a text note: “Observational ecommerce data; no experimental uplift, revenue amount, or referral measurement.”

Keep these sources separate: they have different grains. Joining funnel, cohort, and segment tables would multiply rows and misstate counts. All timestamps are interpreted in UTC.

## Refresh

Run `python -m src.analyze`, then `python -m src.build_tableau`, then reopen the packaged workbook. This replaces the aggregated sources in the package. Publishing to Tableau Public is a separate action and is not performed by this repository.
