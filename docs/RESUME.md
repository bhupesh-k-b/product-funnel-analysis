# Evidence-backed project description

**Product Funnel Analysis | SQL, Tableau, Python**

- Analyzed 2.76M public ecommerce events to build an ordered seven-day view → cart → purchase funnel, identifying 2.14% view-to-cart and 0.67% end-to-end conversion.
- Built SQL retention cohorts with observation-window censoring and compared three first-day engagement signals against subsequent purchase behavior.
- Created Tableau dashboard inputs and a packaged workbook for funnel drop-offs, retention, and behavioral segments; documented AARRR coverage and experiment proposals.

Before claiming a deployed Tableau dashboard, open and verify the workbook in Tableau. Do not claim 18% conversion improvement or 9% retention growth: no intervention was run.
